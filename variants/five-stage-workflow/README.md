# Five-Stage Exam Review Workflow

这是 `build-exam-knowledge-system` 的深度定制分支，面向某个领域、某门学科或某位学习者。

## 五个阶段

1. 结合实际教学资料，构建能直接上考场的学科知识体系。
2. 根据老师重点、分值收益和个人掌握度安排二轮复习。
3. 完整解决用户提供的全部往年题，提炼母题与变式。
4. 只针对薄弱、高频、高分值题型生成专项训练。
5. 根据整个复习过程生成个性化考前半小时提醒。

## 定制维度

- **领域**：数学、经济学、法学、会计、理论课等。
- **课程**：老师术语、符号、案例、重点和命题风格。
- **个人**：时间、目标分数、表达偏好、错误模式与检索习惯。

本分支仍遵守主项目的来源标注、不编造、版权和隐私规则。
