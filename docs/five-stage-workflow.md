# Five-Stage Workflow Branch Guide

本分支把通用项目中的五个阶段设为强制闭环，适合需要深度个性化的复习项目。

## 使用方式

1. 先使用根目录 `SKILL.md` 处理材料与来源。
2. 使用 `variants/five-stage-workflow/SKILL.md` 启动定制工作流。
3. 根据课程选择 `subject_profiles/`。
4. 用掌握状态表驱动阶段二、四、五，不要平均分配复习时间。

## 推荐启动口令

```text
使用 $build-custom-exam-workflow。

根据我上传的本学期课程材料执行完整五阶段复习。
第一阶段的知识体系必须结合老师实际 PPT，能让我看完直接上考场；
第二阶段按分值收益排序；
第三阶段完成全部往年题；
第四阶段只练我的薄弱高分题型；
最后根据全部对话生成考前半小时查漏补缺。
```
