# 真实案例：国际经济学复习

## 课程被压缩成两条主线

```text
国际贸易：
为什么贸易 → 谁受益谁受损 → 政策如何改变福利

国际金融与开放宏观：
国际收支如何记账 → 汇率如何决定 → 内外均衡如何调节
```

这比按 PPT 页码依次复述更有利于识别题目。

## 五个复习模块

1. 贸易理论：技术差异、要素禀赋、规模经济和企业异质性；
2. 利益分配：交换所得、分工所得和不同群体的得失；
3. 贸易政策：关税、配额、出口补贴和生产补贴；
4. 国际收支与汇率：记账、汇率决定和资本流动；
5. 国际收支调整：弹性法、吸收法和内外均衡。

## 答题模板如何从对话中形成

### 贸易政策福利题

```text
政策如何改变国内价格/数量
→ 消费者剩余
→ 生产者剩余
→ 政府收入或财政成本
→ 净福利与无谓损失
→ 政策目的和局限
```

### 国际收支记账题

```text
先判断资金/外汇流入还是流出
→ 再判断借方或贷方
→ 最后检查对应账户
```

### 开放宏观政策题

```text
汇率制度
→ 资本流动程度
→ 政策工具
→ 利率与资本流动
→ 汇率/储备变化
→ 产出和内外均衡结果
```

## 从“原题”到“母题”

真实复习没有停在两套往年卷答案，而是继续提炼：

- 哪些章节重复出现；
- 同一公式如何换参数；
- 小国与大国、固定与浮动汇率等条件如何改变结论；
- 数字计算题如何补上经济含义；
- 简答题怎样同时覆盖机制、利益相关者和政策局限。

## 对 Skill 的贡献

这个案例直接强化了：

- 往年题必须逐题完整做；
- 计算题必须写结果的经济含义；
- 主观题必须列利益相关者；
- 模型结论必须附适用条件；
- 模拟题应改变条件，而不是只换数字。
