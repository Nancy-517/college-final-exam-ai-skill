# 真实案例：发展经济学开卷复习

## 原始任务特征

- 开卷考试；
- 资料是本学期课堂 PPT 和老师重点；
- 题型包括名词解释、简答/画图、计算和可能的开放研究设计；
- 老师明确指出部分模型不考；
- 计算题会沿用 PPT 模型，但可能修改参数。

## 人机协作过程

1. 先盘点课件章节和老师重点，不立即泛泛总结；
2. 从老师口径中确定最高优先级模型和明确排除项；
3. 读取关键章节中的公式、图形与模型说明；
4. 按考试题型重组材料，而不是逐章摘抄；
5. 建立“关键词 → 章节 → 答题落点”开卷索引；
6. 将核心模型整理为“假设、方程/机制、结论、政策含义”卡片；
7. 为开放题建立“现象 → 假说 → 变量 → 识别 → 数据 → 局限”模板。

## 生成成果的结构

```text
第一页：开卷快速索引
第二部分：名词解释库
第三部分：简答与画图模板
第四部分：计算题公式流程
第五部分：开放研究设计模板
第六部分：明确不考内容
```

## 关键经验

### 开卷资料不是越多越好

真实复习中形成的原则是：

> 开卷不是翻书考试，而是定位考试。

过多资料会增加检索成本。考前应保留课堂 PPT、一页索引和少量模型卡。

### 老师的排除项同样重要

明确“不考”的内容应从主线剔除，防止通用教材或 AI 补充把复习范围重新膨胀。

### 计算题按老师符号口径

若课堂 PPT 与通用教材符号不同，应优先使用课堂符号，并在复习资料中单列符号表。

## 匿名化后的开卷索引示例

| 题干触发词 | 立即定位 | 答题动作 |
|---|---|---|
| 营养、劳动能力、贫困陷阱 | 贫困与分配模型 | 画能力曲线，解释收入—营养—劳动能力循环 |
| 二元结构、剩余劳动力、拐点 | 劳动力转移模型 | 写农业与工业部门机制，说明工资和贸易条件变化 |
| 稳态、储蓄率、人口增长 | 增长模型 | 写资本积累方程、稳态条件和比较静态 |
| 关联效应、不平衡发展 | 产业关联模型 | 区分前向/后向关联，解释政策选择 |
| 反常现象、提出假说 | 开放研究设计 | 给出可检验机制、变量、识别策略和局限 |
