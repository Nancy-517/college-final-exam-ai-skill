目标：用一套框架覆盖期末题型：名词解释、判断、选择、简答、计算、材料分析。最高优先级始终是老师划重点。

## 1. 总框架

国际经济学只抓两条主线：

```text
国际贸易：为什么贸易 -> 谁受益谁受损 -> 政策如何改变福利
国际金融/开放宏观：国际收支如何记账 -> 汇率如何决定 -> 内外均衡如何调节
```

复习时不要按 PPT 顺序死看。按下面 5 个模块走：

1. 贸易理论：古典、新古典、要素禀赋、新贸易、新新贸易。
2. 利益分配：贸易所得、自由贸易总福利、不同利益相关者。
3. 贸易政策：关税、配额、出口补贴、生产补贴。
4. 国际收支与汇率：平衡表、借贷、汇率决定、套期保值。
5. 国际收支调整与内外均衡：弹性法、吸收法、不可能三角、蒙代尔、思旺图、IB/EB。

## 2. 理论比较表

| 理论 | 核心假设 | 贸易原因 | 谁受益/谁受损 | 考试关键词 |
|---|---|---|---|---|
| 古典贸易理论 | 劳动生产率不同，技术差异 | 绝对优势/比较优势带来分工 | 国家总体受益；低效率产业可能受冲击 | 绝对优势、比较优势、机会成本雏形 |
| 新古典贸易理论 | 生产可能性边界、机会成本递增 | 相对价格不同，交换改善福利 | 消费者扩大选择，生产结构调整 | PPF、相对价格、交换所得、分工所得 |
| 要素禀赋理论 | 国家资本/劳动等要素禀赋不同 | 出口密集使用本国充裕要素的产品 | 充裕要素所有者受益，稀缺要素所有者受损 | H-O、要素价格、收入分配 |
| 新贸易理论 | 规模经济、产品差异、不完全竞争 | 即使要素相似，也可因规模经济和差异化贸易 | 消费者享受更多品种，企业通过规模降低成本 | 规模经济、产业内贸易、产品差异 |
| 新新贸易理论 | 企业异质性，企业生产率不同 | 高生产率企业更可能出口 | 出口企业扩张，低效率企业退出或受压 | 异质性企业、生产率、出口选择 |

必背总句：

```text
自由贸易通常提高参与贸易国家的总福利，但收益在消费者、生产者、企业和要素拥有者之间分配不均，所以全球化和反全球化会同时存在。
```

## 3. 贸易所得与利益分配

### 贸易所得

| 类型 | 含义 | 答题写法 |
|---|---|---|
| 交换所得 | 即使不改变生产结构，只通过按国际相对价格交换，也能达到更高消费可能性 | “贸易使一国用相对便宜的本国产品换取相对昂贵的外国产品，消费组合改善。” |
| 分工所得 | 根据比较优势调整生产结构，扩大优势产品生产，再通过交换消费更多产品 | “分工使资源配置到机会成本更低的部门，世界总产出提高。” |

### 利益相关者

| 情境 | 受益者 | 受损者 | 解释句 |
|---|---|---|---|
| 进口增加 | 消费者、使用进口中间品的企业 | 进口竞争行业生产者、相关劳动者 | 价格下降提高消费者剩余，但压缩本国竞争部门利润和工资 |
| 出口增加 | 出口企业、出口行业生产者、相关要素拥有者 | 本国消费者可能面对更高价格 | 出口扩大市场和利润，但可能推高国内价格 |
| 要素禀赋贸易 | 充裕要素所有者 | 稀缺要素所有者 | 贸易提高充裕要素需求，改变收入分配 |
| 全球化 | 整体效率、消费者、竞争力强企业 | 部分产业、低技能劳动者、受冲击地区 | 总福利增加不等于人人受益，分配冲突带来反全球化 |

## 4. 贸易政策福利表

小国情形下优先按下表答；若题目明确“大国”，再补一句“可能有贸易条件改善，但仍有扭曲损失”。

| 政策 | 消费者剩余 CS | 生产者剩余 PS | 政府收入/成本 | 国家净福利 | 高频解释 |
|---|---|---|---|---|---|
| 进口关税 | 下降 | 上升 | 关税收入上升 | 通常下降，有生产扭曲和消费扭曲 | 保护本国产业，但牺牲消费者并造成无谓损失 |
| 进口配额 | 下降 | 上升 | 取决于配额租归属 | 通常下降；若配额租给外国更差 | 数量限制导致国内价格上升，配额租归属必须判断 |
| 出口补贴 | 国内消费者受损 | 出口生产者受益 | 政府财政支出增加 | 通常下降 | 鼓励出口但扭曲生产和消费，财政成本高 |
| 生产补贴 | 消费者价格不一定上升 | 受补贴生产者受益 | 政府财政支出增加 | 有扭曲损失，但通常比关税少扭曲消费 | 只刺激生产，不直接限制消费 |

简答题模板：

```text
第一，说明政策如何改变国内价格或产量。
第二，分别分析消费者剩余、生产者剩余、政府收入/财政成本。
第三，指出净福利变化和无谓损失。
第四，补充政策目的：保护幼稚产业、就业、国家安全或反倾销。
第五，指出局限：寻租、效率损失、报复风险、保护难退出。
```

## 5. 国际收支记账表

核心规则：

```text
带来外汇收入或外国对本国付款能力增加：贷方
导致外汇支出或本国对外国付款能力增加：借方
外国资本流入：贷方
官方储备增加：借方
```

| 项目 | 借方/贷方 | 记忆法 |
|---|---|---|
| 商品出口 | 贷方 | 外国给我钱 |
| 商品进口 | 借方 | 我给外国钱 |
| 服务出口 | 贷方 | 外国购买我服务 |
| 服务进口 | 借方 | 我购买外国服务 |
| 收到国外投资收益 | 贷方 | 收入流入 |
| 支付国外投资收益 | 借方 | 收入流出 |
| 收到国外转移支付 | 贷方 | 无偿收入流入 |
| 对外转移支付 | 借方 | 无偿支出流出 |
| 外国购买本国资产/外国资本流入 | 贷方 | 外资进来 |
| 本国购买外国资产/资本流出 | 借方 | 资金出去 |
| 官方储备增加 | 借方 | 央行拿外汇储备，相当于购买外国资产 |
| 官方储备减少 | 贷方 | 卖出储备换回外汇供给 |

考试高频句：

```text
经常项目顺差表示商品、服务、收益和转移等总体净收入为正；逆差表示净支出为正。国际收支调整题要先判断顺差或逆差，再判断政策目标是改善还是扩大。
```

## 6. 计算题公式卡

### 弹性法与马歇尔条件

用途：判断本币贬值能否改善贸易收支。

```text
马歇尔-勒纳条件：
出口需求价格弹性绝对值 + 进口需求价格弹性绝对值 > 1

若 > 1：本币贬值可改善贸易收支
若 < 1：本币贬值可能恶化贸易收支
若 = 1：贸易收支基本不变
```

答题句：

```text
本币贬值一方面提高出口竞争力、减少进口需求，另一方面也会提高以本币计价的进口支出。只有数量效应足够大，即进出口需求价格弹性之和大于 1，贸易收支才会改善。
```

### 吸收法

核心公式：

```text
B = Y - A
B：国际收支/贸易收支
Y：国民收入
A：国内吸收，即消费 + 投资 + 政府支出
```

判断逻辑：

```text
若 Y 增加大于 A 增加：B 改善
若 A 增加大于 Y 增加：B 恶化
逆差减少 = 改善
顺差减少 = 恶化或向均衡调整，按题目目标判断
```

乘数常见写法：

```text
边际储蓄倾向 s = 1 - c
边际进口倾向 m
开放经济乘数常写为 k = 1 / (s + m)
也就是 k = 1 / (1 - c + m)
```

考试步骤：

1. 找出边际消费倾向 `c` 和边际进口倾向 `m`。
2. 算 `s = 1 - c`。
3. 算乘数 `k = 1/(s+m)`。
4. 用乘数算收入变化。
5. 比较收入变化和吸收变化，判断收敛/发散、顺差/逆差改善或恶化。

### 贸易政策福利计算

做题顺序：

```text
1. 画供给需求图。
2. 标出世界价格、政策后国内价格、消费量、生产量、进口/出口量。
3. 分别算 CS、PS、政府收入/补贴成本。
4. 算净福利变化。
5. 写一句经济含义。
```

必须会的面积：

```text
三角形面积 = 1/2 * 底 * 高
矩形面积 = 底 * 高
关税收入 = 单位关税 * 进口量
补贴成本 = 单位补贴 * 补贴数量
```

## 7. 汇率决定与内外均衡

### 汇率决定理论

| 理论 | 核心逻辑 | 适用场景 | 关键词 |
|---|---|---|---|
| 购买力平价 | 汇率由两国价格水平决定 | 长期、商品套利 | 一价定律、通胀、本币贬值 |
| 利率平价 | 汇率与两国利率和预期汇率有关 | 短期资本流动 | 利差、预期贬值/升值、套利 |
| 资产市场方法 | 汇率由资产供求、预期和风险决定 | 金融市场、短期波动 | 预期、资产组合、风险溢价 |

### 内外均衡

| 概念 | 含义 | 考试写法 |
|---|---|---|
| 内部均衡 | 充分就业、物价稳定、经济增长等国内目标 | “内部均衡关注产出和就业是否达到合意水平。” |
| 外部均衡 | 国际收支基本平衡 | “外部均衡关注经常项目/资本流动是否导致持续失衡。” |
| 不可能三角 | 固定汇率、资本自由流动、货币政策独立三者不可兼得 | “一国最多同时实现其中两个目标。” |
| 蒙代尔政策搭配 | 用不同政策分别处理内外均衡 | “通常将财政政策用于内部均衡，货币政策用于外部均衡，按老师 PPT 表述为准。” |
| 思旺图 | 支出改变政策 + 支出转换政策共同实现内外均衡 | “财政/货币等影响总需求，汇率/贸易政策改变支出方向。” |
| IB/EB | 内部均衡线/外部均衡线 | “在图上判断经济所处区域，再选择政策组合。” |

## 9. 材料分析模板

题目若问“全球化/自由贸易/贸易冲突/反全球化”，直接套这个结构：

```text
第一，从总体福利看，自由贸易通过比较优势、规模经济和企业选择效应提高资源配置效率，通常扩大参与国总福利。

第二，从分配效应看，自由贸易并不保证所有利益相关者都受益。消费者通常因价格下降和品种增加受益；出口企业和充裕要素所有者受益；进口竞争行业、低效率企业和部分劳动者可能受损。

第三，从理论解释看，古典和新古典理论强调比较优势和交换/分工所得；要素禀赋理论强调要素收入分配；新贸易理论强调规模经济和产业内贸易；新新贸易理论强调高生产率企业出口和低效率企业退出。

第四，从现实矛盾看，全球化扩大总体收益，但收益分配不均、产业转移、就业冲击和政策自主性下降会推动反全球化。

第五，从政策建议看，应坚持开放，同时通过再培训、社会保障、产业升级、区域补偿和合理贸易政策缓解分配冲突。
```
