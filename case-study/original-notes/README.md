# 个人原始复习笔记

这里保留学生本人在期末复习过程中输入的原始文字，用来展示“零散课堂记录如何被 AI 转化为考试知识系统”。

## 为什么不直接上传原始 DOCX

对用户提供的“517大二下期末考”文件夹检查发现：

- 文件夹约 1.8GB；
- 包含 155 个 PDF、59 个 DOCX、98 个 PPTX，以及其他格式；
- 多份 DOCX 主要由课堂幻灯片截图组成；
- 多份资料带有其他同学署名；
- 多份 PDF 是学校正式往年试卷或教师课件。

即使 DOCX 文件名以个人名字开头，其嵌入图片仍可能是课堂 PPT。为遵守“不上传 PPT”的选择，本目录只保留学生本人输入的文字，不复制课件截图。
