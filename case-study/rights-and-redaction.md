# 公开发布边界与待授权清单

## 已纳入公开分支

- 用户自己的提问与反馈（已脱敏）；
- AI 生成的复习方法、框架和总结；
- 根据真实复习过程重新编排的匿名案例；
- 本项目原创的信息图；
- 不含原题的题型与解题方法摘要。

## 未直接上传

| 材料 | 原因 | 可公开替代 |
|---|---|---|
| 教师课堂 PPT | 可能受版权和校内使用限制 | 章节主题、方法总结、匿名索引 |
| 校内往年试卷原文 | 可能为内部资料或未授权题库 | 母题结构、改编示例、解题模板 |
| 老师划重点原件 | 可能包含教师表达和内部信息 | 脱敏后的优先级规则 |
| 同学笔记或共享资料 | 权利主体不是项目作者 | 仅使用自己生成的总结 |
| 私有聊天完整导出 | 含个人信息、路径和上下文 | 精选原话与语义化来源 |

## 如果希望公开原始附件

请先逐项确认：

1. 上传者是材料权利人，或已获得权利人公开发布许可；
2. 课程或学校规则允许公开；
3. 文件不含姓名、学号、联系方式、内部链接和成绩；
4. 许可范围允许在 GitHub 公共仓库长期保存、复制和再分发；
5. 明确材料采用何种许可证。

在没有这些确认前，本项目只公开衍生方法和匿名案例。

## 重要技术事实

GitHub 的普通分支不能单独设为私有。仓库是公开的，新增分支也会公开；即使以后删除文件，内容仍可能保留在 Git 历史或第三方镜像中。
