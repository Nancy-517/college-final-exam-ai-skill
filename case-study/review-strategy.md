# 从真实复习过程抽象出的策略

## 一句话策略

> 先研究考试，再研究课程；先建立可调用的知识系统，再用往年题和主动输出验证掌握。

## 八步主线

```text
1. 考试约束识别
2. 材料优先级排序
3. 往年题反推命题规律
4. 构建可上考场的知识框架
5. 提炼母题与标准步骤
6. 针对薄弱点做变式训练
7. 压缩为答题模板和视觉索引
8. 考前半小时做个性化提醒
```

## 材料优先级

```text
老师明确重点
> 同课程往年题
> 本学期课堂 PPT
> 作业与课堂例题
> 指定教材
> AI 通用补充
```

这个顺序用于贴合考试口径，不代表高优先级材料在学术上必然更正确。

## 学习者的通用分析模板

### 概念类

```text
它是什么
→ 解决什么问题
→ 与相近概念的区别
→ 在题目中如何使用
```

### 机制与模型类

```text
前提条件
→ 核心变量
→ 作用机制
→ 公式/图形
→ 结论
→ 现实含义
→ 局限
```

### 计算题

```text
识别模型
→ 整理已知
→ 写公式
→ 对齐变量
→ 逐步代入
→ 检查单位和方向
→ 解释结果
```

### 主观题

```text
点明原理
→ 界定概念
→ 分点展开机制
→ 结合材料或案例
→ 总结政策/方法论意义
```

## 三层复习产物

1. **完整理解版**：课程总问题、章节关系、模型、公式、现实意义。
2. **考场模板版**：题型、采分点、公式步骤、关键词定位。
3. **最后 30 分钟版**：个人错点、必背公式、主观题骨架、最后自检。

## 掌握程度的四级评估

| 层级 | 判断标准 | 检验方法 |
|---|---|---|
| 识别 | 看到题目知道考什么 | 只看题干说出章节和方法 |
| 复现 | 能写出标准公式与答案 | 合上资料限时完成母题 |
| 迁移 | 条件变化后仍能推演 | 做参数、背景和问法变化题 |
| 创造 | 能解释新现象并提出方法 | 设计研究、案例或新题 |

真实复习中的总体表现是：识别和复现很强，迁移中上到强，创造能力在部分课程出现，但独立推导和长期记忆仍需巩固。

## 主要优势

- 能快速识别老师命题规律；
- 能把大量 PPT 压缩成有限模型和机制链；
- 能把主观题拆成清晰采分单元；
- 能在不同课程迁移同一分析结构；
- 能持续校准 AI，使输出贴近实际考试。

## 主要风险与修复

| 风险 | 修复动作 |
|---|---|
| 高压依赖 | 提前完成一次低压知识地图 |
| 流畅性错觉 | 合上资料主动回忆和限时输出 |
| 往年题过拟合 | 每个母题至少做一种条件变化 |
| 口径混杂 | 所有结论标注来源，老师口径与通用口径分开 |
| 错题没有闭环 | 按概念、公式、计算、审题、漏点、表达分类 |
| 应试强于长期掌握 | 考后用真实问题再应用一次模型 |
