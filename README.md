# 大学生期末周 AI 速通 90+

> **不是泛泛总结，也不是公共题库。把老师 PPT、考试重点和往年题，编译成一套能识题、能定位、能作答、能拿分的考试系统。**

`college-final-exam-ai-skill` 是一个面向中国大学生的通用期末考试 Skill。它从真实课程资料出发，完成：

**学科框架 → 抢分顺序 → 往年题详解 → 薄弱点变式 → 考前半小时提醒。**

这套方法来自一名**北京航空航天大学（北航 / BUAA）经济学学生**的真实期末周人机协作实践，并在约两周、多门课程的冲刺中取得满意的 **90+** 成绩。北航经济学期末考是本项目的验证场景，项目本身适用于不同学校、不同专业，**与北京航空航天大学及任课教师无官方关联**。

**不会安装 Skill？** 直接使用公开工作台：[大学生期末周 AI 速通 90+](https://college-final-ai-90plus.wangyiqing517517.chatgpt.site)

## 为什么它不只是“让 AI 总结 PPT”

| 普通 AI 复习 | 本项目 |
|---|---|
| 按教材目录泛泛总结 | 按老师重点、PPT 和往年题重建本学期知识系统 |
| 所有内容看起来一样重要 | 按概率、分值、可训练性和个人薄弱点安排抢分顺序 |
| 给出一道题的最终答案 | 拆命题意图、识别线索、完整步骤、采分点、陷阱与变式 |
| 生成大量随机模拟题 | 只围绕高频母题和真实薄弱点举一反三 |
| 考前再复制一遍长笔记 | 根据整段复习记录生成个性化“最后 30 分钟警报” |
| AI 补充与老师口径混在一起 | 明确区分“已确认 / 高频推断 / 补充知识” |

## 六个核心亮点

1. **考试逆向工程**：先识别题型、分值、老师偏好和重复母题，再决定学什么。
2. **来源分级**：老师重点 > 课堂 PPT 与例题 > 往年题 > 教材 > AI 补充，不把通识冒充老师口径。
3. **考场级知识框架**：每个知识点都连接“题干触发词 → 章节/模型 → 解题方法 → 采分答案”。
4. **先拿稳定分**：用出题概率、分值、前置价值、短期得分效率和个人掌握度安排二轮复习。
5. **母题—变式—错因闭环**：会做原题不算掌握，改变数字、条件和背景后仍能答出才算掌握。
6. **双层输出**：保留完整理解版，同时生成考场定位版；既帮助理解，也帮助临场调用。

## 五阶段工作流

```text
01 建体系：结合本学期 PPT，搭出可直接上考场的课程框架
      ↓
02 抢稳定分：优先攻下高频、高分、短期可训练的知识点
      ↓
03 做透往年题：逐题解释思路、公式、采分点、易错点和母题
      ↓
04 只补不会的：围绕薄弱点生成条件变化与综合迁移题
      ↓
05 考前收口：根据个人错题与整段对话生成最后 30 分钟提醒
```

## 真实验证与方法边界

- **验证背景**：北航经济学学生，约两周期末冲刺，多门课程 90+。
- **覆盖过的题型**：经济学模型、政策分析、会计分录、预测计算、马原主观题、开卷检索。
- **真正有效的能力**：材料优先级排序、往年题反推、机制链解释、采分点压缩、视觉索引和临场输出。
- **主要风险**：高压依赖、往年题过拟合、AI 流畅性错觉。Skill 因此强制加入主动回忆、条件变式和来源标注。
- **不作保证**：成绩受到个人基础、考试难度和阅卷标准影响；“90+”是实践结果与目标，不是成绩承诺。

## 分支

- `main`：项目主干。包含通用期末考试 Skill、学科 profiles、答题模板、紧急模式和使用网站。
- `five-stage-workflow`：把复习拆成“建体系—抢稳定分—做往年题—补薄弱点—考前收口”的定制工作流。
- `real-exam-sprint-case-study`：真实复习案例、人机协作记录摘编、复习策略评价与可视化总结。

分支不是三个互相竞争的版本：普通用户从 `main` 开始；需要深度定制时再查看后两个分支。
