# 核心工作流

## 目录

1. 接收考试信息
2. 构建考场级知识框架
3. 安排二轮优先级
4. 完成往年题
5. 针对性训练
6. 考前收口
7. 掌握度跟踪

## 1. 接收考试信息

只提取能够确认的信息，不猜测：

- 考试时间与剩余复习时间
- 开卷或闭卷
- 题型、分值与考试时长
- 老师明确划定的范围
- 资料类型和来源
- 用户目标、基础和薄弱点

开始讲解前，先形成简洁的材料清单。

## 2. 构建可直接上考场的知识框架

不要输出通用教材目录。每个课程单元至少包括：

- 解决什么问题
- 核心概念、理论、模型、公式、图形和前提
- 推导或作用机制
- 与前后章节的联系
- 可能题型与题干触发词
- 考场调用方式和采分点
- 易混概念和常见漏点
- 能确认时标注准确资料位置

框架必须让学生完成：

`题干线索 → 章节/模型 → 方法 → 可得分答案`

## 3. 安排二轮复习

综合评估：

- 老师强调程度
- 往年题出现频率
- 预计分值
- 基础与迁移价值
- 短期可训练性
- 用户薄弱程度

分级：

- **A 必须拿下**：高频、高分、基础，或短期训练能明显提分。
- **B 重点掌握**：常见变式、综合题或区分中高分的内容。
- **C 保底识别**：低频或短期投入收益有限。

给出明确顺序和具体任务，不能只写“复习第三章”。

## 4. 完成全部往年题

每道题包括：

1. 章节、知识点、题型、难度和命题意图
2. 识别线索以及为什么采用该方法
3. 完整的考场式答案
4. 采分点或步骤分
5. 常见错误和快速检查
6. 母题结构与可能变式

全部完成后，总结反复出现的章节、模型、问法、材料和陷阱。

## 5. 生成针对性训练

只为以下内容生成练习：

- 做错或答不出的题
- 高频、高分值薄弱点
- 反复出现的母题
- 改变条件后容易失效的机械记忆

训练顺序：

`识别 → 标准母题 → 条件变化 → 综合迁移 → 易错陷阱`

按照明确采分点判分，并给出下一步最小修复动作。

## 6. 生成考前半小时资料

综合整段对话中的错误、反复提问和作答表现，输出：

- 建议答题顺序和时间分配
- 必须拿下的考点
- 带使用条件的公式与模型
- 主观题答题骨架
- 个性化易错警报
- 开卷定位表
- 最后自检

不要重新复制一轮知识框架。

## 7. 跟踪掌握度

维护简洁状态表：

| 知识点 | 重要度 | 掌握度 | 证据 | 下一步 |
|---|---:|---:|---|---|

证据可以是脱离资料复述、限时解题、变式正确率或采分点覆盖。不能因为用户“看懂了”就标记为已掌握。
